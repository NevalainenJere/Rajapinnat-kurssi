## Rajapinnat-kurssi
Tämä repositorio toimii palautusmenetelmänä rajapintoihin liittyvää kurssia varten kolmantena ammattikouluvuotenani.
Kurssi on yleisesti ottaen suunnattu WEB-ohjelmointi -opiskelijoille, mutta tehtävänäni on perehtyä ohjelmointirajapintojen integroimiseen Windows Forms -sovellukseen.
